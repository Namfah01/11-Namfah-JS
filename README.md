# Mini Project (Shopping Cart)

Developed a responsive shopping cart application using [JavaScript](https://www.javascript.com/) and [Tailwind CSS](https://tailwindcss.com/).

Designed product cards with images, names, and prices, and implemented add-to-cart functionality.

Managed state and dynamically updated the cart and total price using vanilla JavaScript.

Optimized performance and ensured a seamless user experience.

Conducted thorough testing across devices and browsers for consistent functionality.
